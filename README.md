# Saudi Math Live Editor

This folder is designed to be uploaded directly to a GitHub repository and published with GitHub Pages.

- Grade 11: populated with the finalized questions and answer bank.
- Grade 12: populated from the Grade 12 HTML files available in the current workspace.
- Grades 9 and 10: placeholder pages ready to be replaced when their finalized HTML files are available.

IMPORTANT: Before the live editing works, edit `assets/config.js` on GitHub and replace the two placeholders with your Supabase Project URL and Publishable Key.
